BLOX Modules for Automation

Unlock seamless data handling with BLOX

Ready to close the gap between periodic and preventive maintenance?

BLOX Modules for Automation

June 23, 2026

Maximizing system uptime in industrial X-ray applications requires consistent, friction-free access to component data. With the introduction of the BLOX Modules for Automation, Comet X-Ray simplifies the data collection workflow, enabling operators to seamlessly transition from rigid maintenance schedules to continuous, preventive health monitoring.

Data-driven insights are the foundation of modern predictive maintenance. With the launch of the 
BLOX Health Monitoring system
, we started enabling operators to transition from reactive troubleshooting to proactive component care, tracking the performance and longevity of iXRS X-ray tubes and generators.
However, the value of any diagnostic tool depends heavily on the accessibility of its data. To further optimize this workflow, we are introducing the 
BLOX Modules
 – a software utility designed to simplify, accelerate, and automate data extraction from your Comet X-ray generators.

Moving beyond periodic maintenance
Previously, collecting the diagnostic reports for the BLOX platform required a manual process. Technicians had to physically access the generator USB-port and connect a USB flash drive, or log into the WebUI with their credentials on a connected PC.
Reports were typically pulled only once every 6 to 12 months, or reactively after an unplanned breakdown had occurred.

Thanks to the new BLOX Modules, data extraction can be reduced to a single click action, enabling operators to seamlessly pull reports regularly and moving the diagnostic workflow from periodic observation to true preventive maintenance.

Minimal footprint, instant deployment
The BLOX Modules are engineered for maximum integration flexibility with zero impact on existing system architectures.
No hardware modifications:

The solution is entirely software-based.
No generator updates required:
 There is no need to update core firmware.
Rapid deployment:
 The system utilizes simple executable files, allowing implementation to begin immediately.
The core "Easy-Download" functionality relies on just two files: a signed Windows executable (.exe) file that triggers the report download, and a configuration file pre-set with the target generator’s IP address and designated storage folder. When the executable is launched, a progress window opens, automatically routing the diagnostic data to the specified folder.

Modularity across different system configurations
Because industrial X-ray environments vary significantly, the BLOX Modules adapt easily to the three primary deployment scenarios:

                            Bunker with iVario Control Software on a control PC

                            Bunker with iVario Controller

                            Integrated OEM System

Infrastructure requirement
No changes; files reside on the control PC.

1-click extraction method
Manual (or implement a scheduled) trigger of the .exe on the control PC. No login/password required.

Infrastructure requirement
Installation of a standard ethernet switch between generator and controller.

1-click extraction method
User connects a PC with the .exe to pull data directly via the switch. No login/password required.

Infrastructure requirement
Virtual "Pull Health Report" button embedded within the OEM imaging software.

1-click extraction method
One-click background execution; files route to a pre-defined service directory.

Scaling to fully fledged automation: direct vs. restricted internet access
Depending on the IT infrastructure and cybersecurity restrictions of the facility, the modules scale from a local tool into an automated data pipeline using a four-file framework (one signed executable and a config file for the download, and one signed executable and credential file for the upload functions). See how this can look like:

                            Direct internet access

                            Restricted IT environments

If the PC used for data extraction has

direct internet access
, 
the download destination folder is mapped as the uploader’s source folder. The 4-file system handles the entire pipeline autonomously, moving data from the generator straight to the BLOX cloud without human intervention.

If strict factory firewalls prohibit direct internet access, the reports are saved locally on the 
PC used for data extraction
. The data can then be transferred via alternative paths such as manual or automated email forwarding, periodic data mirroring via an IoT edge device, or shared memory protocols on the 
PC used for data extraction
.

Optimize your diagnostic workflow
Transitioning from reactive fixes to proactive uptime management requires consistent, frictionless 
data. 
By removing data extraction barriers, the BLOX Modules make routine health monitoring effortless.
